# TraceLab — ai agent evaluation lab

**[Open the GitHub Pages browser demo](https://skuraganti.github.io/ai-agent-evaluation-lab/)** · [Architecture](ARCHITECTURE.md) · [Data sources](DATA_SOURCES.md) · [Verification](VERIFICATION.md)

Reproducible BFCL-derived tool-planning comparisons, immutable traces, local reference grading, replay, synthetic faults and prompt-injection checks.

## Two ways to explore

The **Pages site** is a self-contained browser demonstration with relative assets and no backend, credentials or model calls. It shows selected historical BFCL-derived tasks, saved model observations and explicitly simulated tool receipts; it does not provide live weather or execute tools. The repository also contains the **full Python/Docker application**; Pages cannot execute its backend or background workers.

## Run the full application locally

Requirements: Python 3.13+, [uv](https://docs.astral.sh/uv/), Docker and Docker Compose. No GPU is required. Run one portfolio stack at a time on a small machine.

```sh
uv sync --frozen
uv run python scripts/bootstrap.py
sh stack.sh up
```

Open **http://127.0.0.1:8285**. Stop with `sh stack.sh stop`; this retains this repository's independent named volume. Helpers honor your current Docker context or explicitly supplied `DOCKER_HOST`; they do not select a personal machine profile. Images/networks/volumes are uniquely named `portfolio-release-*`, keeping the original development stacks separate. Host ports bind to127.0.0.1.

Model integration is **optional through a locally configured host bridge**. Inference may run remotely through the already approved connection. The application starts without a model daemon. A host already configured for the approved `claude-omni` / `cookllm` connection can explicitly start `sh stack.sh bridge`. This repository contains no credentials, included model service or new-provider fallback. The Pages site never contacts that bridge. Recorded evaluations are historical observations and are not regenerated by bootstrap or tests.

## Verify

```sh
uv run pytest
uv run ruff check .
python3 -m http.server 8008 --bind 127.0.0.1 --directory docs
```

The final command previews Pages at http://127.0.0.1:8008. Bootstrap prepares this checkout's own data before data-boundary integration tests. Unit fixtures, actual-source checks, captured evaluations and browser simulations are distinguished in [VERIFICATION.md](VERIFICATION.md). No model call is required for the native test suite.

## Repeated offline baselines and replay

[Run the bounded reproducibility study](evals/BASELINE_REPEAT_PROTOCOL.md) to compare separately generated baseline proposals, outcomes, simulated receipts and semantic hashes across three repetitions of the same 25 original cases. The [replay walkthrough](docs/TRACE_REPLAY.md) follows an immutable saved proposal through parent-linked replay, failure inspection and restart checks. [Recorded results](examples/baseline-repeat-v1.json): the baseline retained 3/25 successes, 20 refusals and 2 wrong-call outcomes in every repetition. These checks make no model requests and are separate from the saved eight-attempt model study.

## Scope and limitations

Tool receipts/faults are simulated, and upstream live filenames refer to historical benchmark contributions. Scores are a local BFCL-derived planning measure, not official leaderboard scores or actual weather fulfillment. Small n1 comparisons establish no causal winner; actual model dollar cost is unavailable.

[DEMO.md](DEMO.md) describes a local walkthrough; [docs/DEMO.md](docs/DEMO.md) describes the Pages interactions.
