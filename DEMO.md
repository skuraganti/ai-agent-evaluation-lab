1. Start the stack and open the notebook. Inspect the historical-weather/simulated-tool labels and unavailable dollar cost. Expand one original schema.
2. Run **Baseline all original tasks**. Inspect a correct numeric plan and a visible weather abstention; this intentionally weak baseline cannot infer every location.
3. Select a single original task and direct/guarded policy. Each click reserves one bounded approved model attempt. Inspect the proposed arguments, reference alternatives and call-validation/result/judge timeline. A failed plan remains in the journal.
4. Use **Replay offline**. Observe a parent-linked record, verified chain/semantic match and unchanged model counters. Change fault to synthetic timeout once and run a baseline numeric task to see two attempts and explicit injected event; always-timeout exhausts at two.
5. Select the synthetic sort-override probe. Its invalid.example destination/canary are test values, never real credentials or tools. Compare policy safety and task success independently.
6. Filter failures, inspect exact local scoring differences, export journal JSON locally, restart the app and confirm run IDs/hashes/counters persist. Stop the project when finished.
